# Проект веб-приложения с рассылкой сообщений

## Описание

В проекте используются Django, Bootstrap

1. Клонируйте репозиторий:
```
git clone https://github.com/username/coursework4.git
```

## Использование:

1. Откройте проект в вашей среде разработки.
2. Запустите проект
```
python3 manage.py runserver
```

## Модуль `config`:
Используется для конфигурации проекта.

## Модуль `newsletter`:
Содержит возможность добавлять, просматривать, редактировать и удалять рассылки.

## Модуль `users`:
Содержит возможность добавлять, просматривать, редактировать и удалять получателей рассылки (клиентов).
## `manage.py`:
Скрипт командной строки, созданный Django.
